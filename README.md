# Tether — MVP Demo

Tether is an AI-powered reciprocal care network that helps people ask for small forms of real human support **before disconnection turns into crisis**.

This MVP is built as an investor-ready journey with a calm, private, mobile-first UX.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Product principles

- Dignity-first support matching
- Not therapy, not social media, not an AI companion
- Clear boundaries for both people requesting and offering care

## Included pages

1. Landing page (`/`)
2. Sign in / sign up (`/auth`)
3. Dashboard (`/dashboard`)
4. “I need support” flow (`/need-support`)
5. AI support-card review (`/need-support/review`)
6. “I have capacity” flow (`/have-capacity`)
7. Match results (`/matches`)
8. Safety resources (`/safety`)

## Mock AI & matching behavior

- Realistic sample users and support requests are in `lib/sample-data.ts`.
- Matching logic scores support fit using support type, format, urgency, bandwidth, and reliability in `lib/matching.ts`.
- Support-card wording is generated by `generateSupportCard` in `lib/support-card.ts`.

## Empty states

Polished empty-state panels are included in:

- Dashboard (no active requests scenario)
- Match results (no immediate matches scenario)

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Demo journey

1. Open landing page and continue to auth.
2. Enter dashboard and choose **I need support**.
3. Complete request inputs and review generated support card.
4. Send request and view match results.
5. Explore **I have capacity** and **Safety resources**.
